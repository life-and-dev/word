# Rules

## Authoring

* Never Markdown link bible verses.
* Conclusions contain inline md links to article anchors.
* When formatting text, keep inline md links.
* Prefer ESV, unless comparing textual variations.
* Use UPPERCASE LORD for YHWH and Lowercase Lord for Jesus, unless both YHWH and Jesus are discussed, then use "the Father" to refer to YHWH.
* **bold** keyword in quoted scriptures discussed in article.
* opinions are quoted in *italics*

## Evidence

Prefer this order of evidence:

1. OT inspired scripture (YHWH said...) <-- most reliable
2. Other Bible scriptures, excluding Ezekiel, Luke, Hebrews, Revelation
3. Only quote Ezekiel, Luke, Hebrews, Revelation if confirming, but never sole evidence
4. Aramiac, Hebrew, Greek dictionary definitions
5. Scholar commentary about Aramiac, Hebrew, Greek lexicon
6. Wikipedia / articles with verifiable sources
7. Extra biblical texts: only quote to compare language/idioms/culture <-- least reliable
